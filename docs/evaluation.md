回答质量由两组独立Agent在各批全48题冻结后，对照完整原始对话逐题审阅，每组负责固定两份会话24题；标准答案只在评测侧使用。正确要求必要事实完整且有原文依据，部分正确表示遗漏必要事实，错误包括矛盾、无依据的关键主张或原文已有答案却拒答；真实追问、工作台失败及未发布另列。每批六类合计48题，保留实际回答、判定理由、证据和标注问题。

Evidence Recall 取最后一次实际派发的作答模型输入，若派发复核则取复核输入，否则取主要作答输入，并核对真实消息包装与冻结目录。每题计算有效证据编号进入该输入的比例，再对47题取平均；`conv-47 / qa_index=38` 的无效原标注保留并输出 null。已证明未进入作答输入的题目记0，缺少输入证明时指标为 null。初批46题、修复批2题未进入作答输入，输入证明缺失均为0。

耗时从正常工作台提交到响应结束，包含该题实际检索、阅读、生成、复核、重试及失败，按全48次尝试计算；P95使用 nearest-rank。它测量服务器内部工作台请求，公网浏览器往返另行测量。本机向量按批次原生基线单列：初批198次，包括196成功、1失败、1未知，已知耗时1,310.578秒，完整耗时为 null；修复批11次全部成功，共7.641秒。初批原未知记录、退出码1和已退出进程证明保留；修复批正常退出、原生待结束尝试0、模型已卸载。

`retrieve@8` 修复了有原件却在空上层停止的问题：同一次查询只在当前层没有合格候选时检查下一层，到首个非空层暂停并交回模型。服务器同查询零模型对照为旧策略选0条、新策略选3条；模型决策限额、项目与场景范围、来源资格及原回答校验保持。修复批沿用相同题目，作为本次修复复验单独列出。
