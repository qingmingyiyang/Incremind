# 示例资料

用来体验 Incremind 的几份公开示例，内容都是自己写的，不含任何个人信息。

按顺序把它们发进工作台（直接粘贴文字，或拖文件进输入框）：

| 文件 | 想看的效果 |
|---|---|
| `01-间隔重复入门.md` | 记住：生成整理稿和摘要，提炼出几条认识，并自动新建一个项目 |
| `02-主动回忆与自适应间隔.md` | 信息增量：归进同一个项目，只提炼相对第 1 份**新增**或**不同**的内容 |
| `03-成都周末行程.md` | 自动归属：识别出新主题，自动新建一个旅行项目 |

然后试试：

- 一句话里既要记又要问：`记一下周五前交物业费，另外问下主动回忆和重读哪个效果更好？`
- 提问并查看引用：`复习间隔应该怎么安排？`（在"日常"里直接问，资料已被归到别的项目时会自动转过去回答）
- 去 **资料库** 一键确认提炼出的认识。
